# 工藤正士の業務実績

AIを活用したWeb・自動化、出版・メディア、映像、調査・研究などの取り組みを紹介する、日本語の静的ポートフォリオです。

## 公開用の構成

`index.html` は、スタイル、動作、28件の実績データ、説明図4点をすべて含む完成ファイルです。外部のJavaScriptライブラリ、CDN、外部フォント、APIキー、サーバー側の処理を必要としません。

GitHub Pagesは `main` ブランチの `/ (root)` を公開元として使用します。パスを固定した外部ファイルへの参照がないため、リポジトリ配下でも表示できます。

### 主な機能

- 代表的な取り組み6件
- 業務のご依頼・ご相談の案内とメールボタン（nekobus775@gmail.com）
- 7分野・28件の業務・活動実績
- キーワード、分野、取り組みの段階を組み合わせた絞り込み
- 各実績の背景、担当内容、作成物、AIの役割、技術・環境
- 詳細URLのコピー、一覧へ戻ったときの検索条件保持
- 説明図の拡大、スマートフォン用メニュー
- キーボード操作、動きを減らす設定への対応

## 内容を更新する場合

このリポジトリでは、`index.html` の更新だけで文章・デザイン・動作を反映できます。編集する箇所は次のとおりです。

- デザイン：`<style>` 内
- 実績データ：`id="portfolio-data"` のJSON
- 説明図：`id="portfolio-figures"` のJSON
- 検索・詳細表示：末尾のJavaScript

画像のbase64データを手作業で変更する必要はありません。新しい実績を追加する場合は、一意の `id` と `slug` を割り当て、公開してよい本文・関連URLのみを入力してください。

## 掲載内容の扱い

公開・運用中の成果だけでなく、研究、試作、企画、職務経験も含みます。投稿と採択、試作と本番運用、仮定に基づく試算と実測成果などを区別しています。

TOYOTAの項目は公募向け映像の制作活動であり、委託制作・公式採用・受賞を表すものではありません。公募の提供映像そのものはこのサイトに埋め込んでいません。
